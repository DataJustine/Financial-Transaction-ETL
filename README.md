# Financial Transactions ETL Pipeline

End-to-end ETL pipeline built using Python (pandas and numpy), PostgreSQL, and PowerBI.

## Project Workflow
1. Exploratory analysis and data profiling were performed in Jupyter notebooks.
2. Final ETL logic was modularized into Python scripts for maintainability and reuse.
3. Cleaned data was loaded into PostgreSQL and validated using SQL queries.
4. Visualizations created using PowerBI.

Notes for Visuals:
Transaction activity declines significantly after 2023. Review of the source data identified fewer transaction records in later years as well as approximately 990 records with missing transaction dates. The trend should therefore be interpreted within the context of the source data limitations.
