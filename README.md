# Financial Transactions ETL Pipeline

This project demonstrates a full ETL workflow using Python, SQL and data visualization in PowerBI.

It follows the process of taking messy financial transaction data, cleaning it with Python, loading it into a structured SQL model and generating 
Power BI dashboards. Then using this information to provide results and recommendations to the business.

## Steps
- Extract raw CSV files
- Transform data (cleaning, validation, standardization)
- Load into SQL
- Generate dashboards for analysis
- Conclusions and recommendations
